**LiteEditorAI v1.1.123** — лёгкий редактор для работы с ИИ-агентами в терминале.

**AI-DB: чат с базой стал рабочим инструментом — управляемый ответ, честный контекст и защита на уровне СУБД.**

Агент писал SELECT и сам решал, каким будет вывод: вмешаться в отчёт было нечем. Структуру большой
базы он видел обрезанной по объёму — нужная таблица могла в неё не попасть. А «только чтение»
держалось на списке запрещённых слов. Этот релиз закрывает все три темы разом.

## ✨ Что появилось
- **«Выполнить с промптом».** Рядом с «Выполнить» — поле «Что учесть в ответе» с готовыми
  заготовками и `Ctrl+Enter`: инструкция уходит агенту вместе с результатом, поэтому вывод следует
  вашему указанию, а не представлению модели об отчёте.
- **Управление выводом.** Переключатель «Авто-вывод» и разовое «выполнить без вывода»: результат
  можно просто посмотреть, а вывод запросить позже кнопкой.
- **Переспросить и переписать вопрос.** Последний ответ пересоздаётся одной кнопкой; своё сообщение
  можно отредактировать — всё, что было после него, соберётся заново.
- **Инструкция сессии** — правила ответа, глоссарий, особенности данных. Уезжает агенту с каждым
  вопросом и действует только в этой сессии. Сессии теперь переименовываются и ищутся.
- **Честный контекст вместо обрезки.** Подробную структуру получают закреплённые и упомянутые
  в разговоре таблицы, остальные видны списком имён — на базе в сотни таблиц агент больше не теряет
  нужную и сам запрашивает недостающую структуру. Плюс комментарии таблиц и колонок и частые
  значения полей (`status → paid, refunded`), чтобы запросы не уходили мимо данных.
- **Разбор ошибки СУБД:** упавший запрос агент объясняет и сразу предлагает исправленный.
  **План из нескольких запросов** выполняется по очереди одной кнопкой.
- **Расход агента** — токены и стоимость сессии в шапке чата.
- **Экспорт сессии в отчёт** — Markdown или HTML (в HTML графики сохраняются картинками).
- **Запрос к другой базе:** схемы дополнительных подключений добавляются в контекст, а выполнить
  запрос можно на выбранной базе — сравнение двух баз больше не упирается в одно подключение.

## 🔒 Безопасность
- **Только чтение теперь обеспечивает сама СУБД:** запросы AI-вкладки идут в транзакции `READ ONLY`
  (PostgreSQL/MySQL) или под `PRAGMA query_only` (SQLite); прежняя проверка по списку слов осталась
  вторым эшелоном. Время запроса ограничено, на PRODUCTION-подключении — подтверждение и `LIMIT`.
- **Флаг «не отправлять данные во внешние модели»** на подключении: агент получает только структуру,
  без строк результата и примеров значений.
- **Промпт больше не виден в списке процессов** — Codex получает его через stdin, как и Claude.
- **Отмена выполняющегося запроса** прямо из карточки результата.

## 🛠 Под капотом
Чат перерисовывается точечно: графики и таблицы прошлых сообщений переживают новый ход, ответ
в потоке сразу форматируется как markdown. Транскрипты переехали в `~/.LiteEditorAI/dbai/`.
Английский и китайский словари снова на 100%.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.61.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
