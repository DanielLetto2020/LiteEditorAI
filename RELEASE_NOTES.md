**LiteEditorAI v1.1.99** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Новый модуль «Внешние хранилища»: полноценный браузер S3-совместимых хранилищ (AWS, MinIO,
Cloudflare R2, Yandex Object Storage и др.) — дерево бакетов, просмотр файлов прямо из бакета,
загрузка/скачивание с прогрессом и управление публичностью объектов.**

## ✨ Добавлено
- **Модуль «Внешние хранилища»** (кнопка ☁️ в квикбаре). Архитектура адаптерная: первый адаптер —
  **S3**, вкладки WebDAV/FTP уже видны как «скоро».
- **Подключения проектные и общие**: вкладки «Проект / Общие» — хранилища проекта живут в его
  области, перенос между областями одной кнопкой. Категории, цвет окружения, метка **PRODUCTION**
  (подтверждение разрушающих операций), режим **«только чтение»**.
- **Форма подключения** с кнопкой «Тест»: endpoint (пусто = AWS), регион, path-style для MinIO,
  ключи (+ «Сейф паролей»), Session Token, бакет по умолчанию, базовый URL публичных ссылок.
  **Анонимный режим** — просмотр чужих публичных бакетов вообще без ключей.
- **Браузер хранилища**: ленивое дерево бакетов и папок, таблица объектов с хлебными крошками и
  пагинацией (тысячи объектов дозагружаются кнопкой), свойства объекта.
- **Просмотр прямо из бакета**: код с подсветкой (читаются только первые 2 МБ — гигабайтный файл
  не качается целиком), картинки, для бинарных — карточка со скачиванием.
- **Передачи с прогрессом**: загрузка кнопкой или **перетаскиванием из системы**, скачивание в
  выбранную папку, полоса прогресса со скоростью и **отменой**, multipart для больших файлов.
- **Приватный / публичный**: статус доступа у объекта, открытие/закрытие публичного доступа в один
  клик, копирование публичной ссылки и **временные подписанные ссылки** со сроком до 7 суток.
- Операции: папка, переименование, копирование, удаление (в т.ч. папки целиком — с подтверждением).

## 🔒 Безопасность
- Ключи шифруются системным хранилищем и не покидают бэкенд-процесс.
- «Только чтение» и «анонимно» блокируют запись **на бэкенде**, а не только в интерфейсе —
  включая подписанные ссылки на запись.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.61.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
