**LiteEditorAI v1.1.249** — лёгкий редактор для работы с ИИ-агентами в терминале.

Zero-Trust MCP Hub с правой колонкой инструментов, каталогом модульных паков (`db`, `servers`, `containers`) и пресетом для локальной разработки; поддержка Antigravity CLI (`agy`) в AI-чате модуля «Базы данных» и усиление безопасности SQL/контейнеров.

## ✨ Добавлено

- **Zero-Trust MCP Hub и панель «MCP-инструменты» (`Ctrl+Shift+M`).** Локальный UDS-хаб (`~/.LiteEditorAI/run/mcp.sock`) и лёгкий stdio-мост `mcp/lite-mcp-bridge.js` для подключения `claude`, `agy`, `codex` и `gemini` с сессионными токенами в каждом терминале проекта:
  - 3 модульных пака в **MCP Store**: **Базы данных** (9 read-only инструментов), **Серверы и SSH** (11 read-only инструментов) и **Контейнеры** (8 read-only инструментов для Docker/Podman);
  - правая колонка с лентой вызовов («Сессия / Проект / Все») и карточками HITL-подтверждения для `isProd` и непривязанных ресурсов;
  - пресет **«Разрешить все non-prod БД и локальные контейнеры (read-only)»** (`dev_safe`), строгий Zero-Trust (`strict`) и защита `noCloud` для облачных моделей;
  - редактирование секретов/паролей и jsonl-аудит без чувствительных данных.
- **Antigravity CLI (`agy`) в модуле «Базы данных».** Возможность использовать `agy` прямо в AI-чате БД наравне с Claude Code, Codex, Gemini и OpenRouter.

## 🔒 Безопасность и исправления

- **Усиление защиты модулей «Базы данных», «Контейнеры» и «Серверы»** (AST read-only SQL-валидация, безопасное экранирование и таймауты).
- **Все 23 модуля в `Ctrl+K` и на быстрой панели**, динамическое обновление всех подсказок горячих клавиш на лету, исправленные переводы интерфейса (5422 строки, EN/ZH 100%) и пути `app.asar.unpacked` в пакетах `.deb` / `.tar.gz`.
- **Удалены** устаревший модуль «ИИ компания» (`quorum`) и остатки удалённого лендинга.

Полный список изменений — в [CHANGELOG](https://github.com/DanielLetto2020/LiteEditorAI/blob/main/CHANGELOG.md).

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./liteeditor-ai_*.deb`, затем иконка **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.

> Alpha: при перезагрузке окна живые терминалы подхватывают последние 128 КБ экрана; при полном закрытии приложения сохраняются только имена вкладок. Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
