**LiteEditorAI v1.1.204** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Сквозной аудит редактора и модулей: закрыты дыры в безопасности, случаи потери данных, зависания
и утечки.** Около 250 точечных исправлений в ядре и почти во всех модулях, нового поведения нет.

![LiteEditorAI](https://raw.githubusercontent.com/DanielLetto2020/LiteEditorAI/main/assets/screenshots/hero.png)

## 🔒 Безопасность

- **Режим «только чтение» в базах данных** разбирает SQL по лексике своей СУБД: `DROP` в строках и
  комментариях чужих диалектов, `SET`/`PREPARE` и функции с побочными эффектами больше не проходят.
  Закрыта SQL-инъекция через значения ячеек в MySQL.
- **Текст из модулей вставляется в терминал как вставка** (bracketed paste): переводы строк не
  выполняются в shell, управляющие символы не уходят как нажатия клавиш.
- Пароли подключений не раздаются во все окна; имена веток git проверяются; закрыт path traversal в
  пользовательских модулях, S3, Jira и `.claude`; `file://` на исполняемые файлы не запускается.
- «Мониторинг сайтов»: кастомный предикат не выбирается из песочницы, заголовки авторизации не уходят
  по редиректу на чужой хост. Скрытые окна SEO и мониторинга закрыты от `window.open`.

## 🐛 Исправлено

- **Потеря данных**: откат из локальной истории, Git-discard и замена по проекту сначала сохраняют
  текущую версию; CRLF-файлы не переводятся в LF; правки SQLite из консоли доходят до файла; скачивание
  из S3 не удаляет существующий файл при ошибке; история чатов OpenRouter снова сохраняется; вивер не
  пишет в бинарные файлы.
- **Зависания**: петли симлинков, обрывы сети в обновлении, стримах, SEO, Jira и RabbitMQ.
- **Утечки**: шеллы закрытых окон, SSH-сессии и туннели, зомби-консюмеры Kafka, агенты после закрытия
  окна и выхода под обновление.
- **Кириллица на стыке чанков** («��») во всех потоковых модулях.
- **Git**: имена файлов с кавычками и юникодом, коммит после конфликта, blame больших файлов; сбой git
  больше не выдаётся за «различий нет».
- Полный список — в [CHANGELOG](https://github.com/DanielLetto2020/LiteEditorAI/blob/main/CHANGELOG.md).

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка
  не нужна). Сборка без подписи, поэтому SmartScreen может предупредить: *Подробнее → Выполнить в любом случае*.
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому
  при **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение →
  откройте **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите
  **«Открыть всё равно»**. Кому удобнее терминал — то же одной командой:
  `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: терминалы переживают перезагрузку окна, но не перезапуск редактора (сохраняются только
> имена вкладок). Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
