**LiteEditorAI v1.1.176** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Редактор научился обновлять себя сам.** Раньше плашка о новой версии просто открывала страницу
загрузки: скачать, распаковать, заменить файлы — всё руками. Теперь достаточно одного нажатия.
Новая версия скачивается в фоне, а по кнопке **«Перезапустить»** редактор закрывается и открывается
уже обновлённым.

> ⚠️ **Это обновление — последнее, которое нужно поставить вручную.** Версии, установленные раньше,
> механизма самообновления не содержат. Начиная с этой, всё дальнейшее будет приходить одной кнопкой.

## ✨ Добавлено

- **Обновление в один клик.** Плашка рядом с номером версии стала кнопкой на все состояния:
  «↑ v1.1.177» → «↓ 42 %» (прогресс прямо в плашке, повторное нажатие отменяет загрузку) →
  «⟳ Перезапустить». Перед перезапуском редактор обязательно переспросит: обновление завершает
  терминалы вместе с запущенными в них агентами.
- **Портативная сборка для Linux** — `LiteEditorAI-1.1.176-alpha-linux-x64.tar.gz`. Распаковывается
  в домашний каталог, не требует прав root и **обновляется без пароля**. Установка из `.deb` тоже
  обновляется одной кнопкой, но один раз спросит пароль администратора — пакет живёт в системном
  каталоге, и заменить его может только root.
- **Раздел «Обновления» в настройках**: скачивать в фоне (по умолчанию), только сообщать о новой
  версии или не проверять вовсе. Там же — подсказка о том, как обновляется именно ваша установка,
  и кнопка проверки. Проверка теперь идёт не только при запуске, но и раз в три часа: редактор
  часто держат открытым сутками.

## 🔒 Безопасность

- Скачанный файл проверяется по контрольной сумме **sha256** и по размеру. Мы запускаем этот код на
  вашей машине, поэтому расхождение означает отказ установить обновление, а не «наверное, сойдёт».
- Замена происходит целиком: каталог приложения отодвигается, новая версия встаёт на его место, и
  только после успеха старая удаляется. Если что-то пойдёт не так, редактор вернётся к прежней
  версии — остаться с наполовину обновлённой установкой невозможно.

## 🐛 Исправлено

- **Плашка о новой версии выглядела как серая системная кнопка.** При удалении Android-пульта
  в v1.1.174 в таблице стилей остался фрагмент без селектора, и браузерный движок отбрасывал вместе
  с ним следующее правило — как раз оформление этой плашки.

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка
  не нужна). Сборка без подписи, поэтому SmartScreen может предупредить: *Подробнее → Выполнить в любом случае*.
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому
  при **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение →
  откройте **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите
  **«Открыть всё равно»**. Кому удобнее терминал — то же одной командой:
  `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
> Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
