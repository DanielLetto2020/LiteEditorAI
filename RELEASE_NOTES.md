**LiteEditorAI v1.1.205** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Ваши данные больше не пропадают и не портятся при сбоях диска, двойных нажатиях и параллельных
сохранениях.** Рекурсивный аудит редактора и модулей: около 60 исправлений, нового поведения почти нет.

![LiteEditorAI](https://raw.githubusercontent.com/DanielLetto2020/LiteEditorAI/main/assets/screenshots/hero.png)

## 🐛 Исправлено

- **Ошибка чтения больше не выглядит пустым списком**: задачи, напоминания, история чатов, штат «ИИ
  компании» и список проектов не затираются «пустотой», если файл временно не прочитался; повреждённый
  файл откладывается рядом, а не перезаписывается.
- **KeePass**: двойной клик по «в сейф» больше не делает базу нечитаемой.
- **Параллельные сохранения одного файла** (автосохранение и Ctrl+S, два окна, удалённый хост) идут по
  очереди — на диске остаётся последняя версия, а не старая или смесь двух.
- **Синхронизация ПК↔сервер** не уносит в корзину весь проект, если каталог на другой стороне пропал, и
  не удаляет его при повторном подключении.
- **Кодировки и концы строк**: файлы не в UTF-8 открываются только для чтения, «Обработка текста» не
  трогает `.docx` и двоичные файлы, не переписывает Markdown и сохраняет CRLF-файлы в CRLF.
- **Выход и обновление** спрашивают о несохранённом в окнах модулей.
- «Контекст», «ИИ компания», задачи и календарь, базы данных, RabbitMQ и Kafka, удалённые хосты, S3 и
  Jira: двойные отправки, затёртые правки агента, обрубки файлов при обрыве связи.
- Полный список — в [CHANGELOG](https://github.com/DanielLetto2020/LiteEditorAI/blob/main/CHANGELOG.md).

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка
  не нужна). Сборка без подписи, поэтому SmartScreen может предупредить: *Подробнее → Выполнить в любом случае*.
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому
  при **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение →
  откройте **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите
  **«Открыть всё равно»**. Кому удобнее терминал — то же одной командой:
  `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: терминалы переживают перезагрузку окна, но не перезапуск редактора (сохраняются только
> имена вкладок). Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
