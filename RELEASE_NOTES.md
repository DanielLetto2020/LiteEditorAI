**LiteEditorAI v1.1.114** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Интерфейс заговорил на трёх языках: English, 简体中文, Русский — и языки стали подключаемыми файлами.**

## ✨ Добавлено
- **Локализация всего интерфейса.** Английский и упрощённый китайский переведены полностью — по 3820 строк
  каждый: меню и шапка, настройки, каталог модулей, все 21 модуль, сообщения об ошибках, подсказки, диалоги
  и системный трей. Язык выбирается в **«Настройки → Язык интерфейса»** и применяется **сразу** — без
  перезапуска и без переоткрытия уже открытых окон модулей.
- **Языки — подключаемые файлы.** Каждый язык это обычный JSON `locales/<код>.json`, где ключ — исходная
  строка. Свой язык добавляется **одним файлом без пересборки**: положите его в
  `~/.LiteEditorAI/locales/<код>.json` — кнопка **«Открыть папку языков»** в настройках ведёт прямо туда.
  Этот каталог перекрывает встроенные языки, так что им же можно поправить одну неудачную формулировку в
  готовом переводе, положив в свой файл только этот ключ. Непереведённые строки показываются по-английски.
- **README на трёх языках** — английский стал основным лицом проекта, русская версия переехала в
  `README.ru.md`, добавлена китайская `README.zh.md`.
- **Свежие скриншоты и демо-ролик** вместо устаревших: рабочее место с тремя агентами в разных состояниях,
  код и Git одним окном, каталог из 21 модуля, коллаж шести тем и короткий GIF-тур по интерфейсу.

## 🐛 Исправлено
- **Окна модулей открываются заметно быстрее.** Запрос словаря — синхронный и приходит при старте каждого
  окна — по пути читал и разбирал все файлы локалей целиком (около 970 КБ JSON, ~33 мс блокировки на окно,
  и так каждый раз). Теперь разобранные словари кэшируются, а сам ответ не обращается к диску.
- **На русском интерфейсе перевод не тратит ничего** — наблюдатель за DOM больше не подключается, когда
  переводить нечего. Для остальных языков правки складываются в один пакет и не вызывают повторных проходов.
- **Имена вкладок и сессий** собирались склейкой и потому не переводились: теперь на английском вкладка
  называется `Terminal 2`, на китайском — `终端 2`.
- **Файлы локалей попадают в дистрибутив** — без этого в установленной сборке не было бы ни английского,
  ни китайского.

Перевод применяется по точным совпадениям со словарём, поэтому имена ваших проектов и файлов, вывод
терминала, код в вивере и прочие данные не затрагиваются.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.61.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
> Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
