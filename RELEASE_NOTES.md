**LiteEditorAI v1.1.190** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Когда проектов много.** Список слева перестаёт читаться, когда в нём десятки папок: заголовки категорий
уезжают за край при прокрутке, а нужный проект приходится искать глазами. И отдельная давняя нехватка:
поиск жил внутри одного проекта, поэтому «где же я это писал» выяснялось перебором — открыть проект,
поискать, открыть следующий.

Этот релиз про то и другое.

## ✨ Добавлено

- **«Найти во всех проектах»** — `Ctrl+Shift+F` открывает отдельное окно поиска сразу по всем вашим
  проектам. Четыре области на выбор: **содержимое файлов**, **имена файлов**, **то и другое** и
  **вывод открытых терминалов** — прежний «поиск по всем терминалам» никуда не делся, он стал одним из
  режимов этого окна.
  Результат приходит **потоком**: первые попадания видны почти сразу, а не после обхода всех проектов,
  и долгий поиск в любой момент останавливается кнопкой.
- **Область поиска задаётся явно.** Слева — список проектов с галочками и готовые наборы: все,
  избранное, текущий, любая ваша категория. Рядом — маски путей (`только файлы: *.js, src/**` и
  `кроме: *.min.js, dist/**`), учёт регистра, поиск слова целиком и регулярные выражения.
- **Выдача разложена по проектам и файлам** — с подсветкой совпадений и счётчиком на каждом уровне,
  чтобы сразу видеть, где находка одна, а где их сорок. Справа показывается предпросмотр найденного
  места с окружающими строками. `Enter` или двойной клик переключает активный проект и открывает файл
  на нужной строке в вивере; по результатам можно ходить стрелками, не трогая мышь.
- **История запросов** — последние поиски лежат под полем ввода и повторяются одним нажатием.
- **Фильтр списка проектов.** Над сайдбаром появилось поле: набрали пару букв — остались совпадения
  по имени или пути, пустые категории скрылись, а свёрнутые раскрылись сами, чтобы находки не прятались.
  `Esc` сбрасывает фильтр, `Enter` открывает первый найденный проект.

## 🔧 Изменено

- **Заголовки категорий теперь липнут к верху списка** при прокрутке — в длинной колонке всегда видно,
  в какой категории вы находитесь.

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка
  не нужна). Сборка без подписи, поэтому SmartScreen может предупредить: *Подробнее → Выполнить в любом случае*.
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому
  при **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение →
  откройте **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите
  **«Открыть всё равно»**. Кому удобнее терминал — то же одной командой:
  `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
> Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
