**LiteEditorAI v1.1.94** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Полоса вкладок-терминалов доведена под авто-имена от агента: длинные имена задач теперь читаемы —
вкладки шире, полоса прокручивается стрелками, а полное имя всплывает подсказкой. Заодно вкладка
перестала мигать служебным заголовком самого шелла.**

## ✨ Добавлено
- **Прокрутка полосы вкладок**: вкладка, переименованная агентом (имя пришло из заголовка терминала),
  стала шире — под длинный текст задачи; когда таких вкладок много, полоса прокручивается стрелками
  **‹ ›** (они появляются только при переполнении), а активная вкладка всегда подкручивается в видимую
  область. Кнопка **«+»** (новая вкладка) вынесена в постоянную позицию и больше не «уезжает» за край.
- **Подсказка с полным именем**: если имя вкладки не помещается и обрезано многоточием, наведение
  мышью показывает его целиком.

## 🐛 Исправлено
- Вкладка больше **не подхватывает служебный заголовок самого шелла** (`user@host`, путь вида
  `~/project`, `C:\path`) — до первого осмысленного заголовка от агента она остаётся «Терминал N»
  (раньше могла мигнуть путём или строкой приглашения). Ручное переименование возвращает вкладке
  обычную ширину.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.60.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
