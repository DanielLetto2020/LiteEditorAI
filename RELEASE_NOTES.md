**LiteEditorAI v1.1.215** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Поддержка Windows и macOS прекращается: релизы теперь только для Linux.** Мы собираем и публикуем одну платформу,
поэтому выпуски выходят проще и быстрее.

## ⚠️ Важно для пользователей Windows и macOS

- **Начиная с этой версии сборки для Windows и macOS не публикуются.** В релизе два файла: `.deb` и портативный
  `tar.gz` (Linux, x64).
- **Последняя версия для Windows и macOS — [1.1.214](https://github.com/DanielLetto2020/LiteEditorAI/releases/tag/v1.1.214).**
  Установленная у Вас сборка продолжит работать, но новых версий для неё не будет: плашка обновления отправит на
  страницу релизов, где файла для Вашей системы уже нет.
- Исходный код остаётся открытым: из исходников (`npm install && npm start`) редактор запускается, но мы это
  не проверяем и поддержки не обещаем.

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.

> Alpha: терминалы переживают перезагрузку окна, но не перезапуск редактора (сохраняются только
> имена вкладок). Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
