**LiteEditorAI v1.1.247** — лёгкий редактор для работы с ИИ-агентами в терминале.

Ссылки в выводе агентов теперь открываются по клику, терминал меньше подтормаживает при перетаскивании панелей и смене шрифта, а модуль «Базы данных» надёжнее ведёт себя при сбоях транзакций.

## 🐛 Исправлено

- **Гиперссылки в терминале открываются по клику.** Claude Code и другие программы выводят кликабельные ссылки (OSC 8). Раньше клик показывал системный диалог, после которого ничего не открывалось. Теперь веб-ссылки открываются в браузере, а ссылки на файлы — во вьювере «Проект», с переходом к строке. Работает во всех терминалах редактора; в терминалах удалённых хостов и контейнеров — только веб-ссылки.
- **«Базы данных»: соединение после неудачного отката транзакции.** Если откат сам завершился ошибкой, соединение больше не остаётся внутри открытой транзакции — оно закрывается, а следующий запрос открывает новое.
- **«Базы данных»: индикатор соединения во время долгого запроса** больше не зависает и не краснеет — он сразу показывает «Соединение активно (выполняется запрос)».
- **Журнал ошибок без ложных тревог:** предупреждения Node об устаревших API и намеренное освобождение WebGL-контекста больше не считаются ошибками.

## ⚡ Производительность

- При перетаскивании разделителей и слайдера ширины терминал подстраивается не чаще 10 раз в секунду (и точно — при отпускании мыши), а не на каждом кадре.
- WebGL-контексты терминалов освобождаются сразу при вытеснении и не копятся.
- Новый размер шрифта применяется к скрытым вкладкам в момент их показа, а не ко всем терминалам сразу.

## 🧰 Под капотом

- Новый модуль разбора ссылок `lib/termlink.js` и модульные тесты `termlink`, `db-queue`, `logger-level`.
- Диагностика тормозов терминала по переменной окружения `LITE_TERM_TRACE=1`.

Полный список изменений — в [CHANGELOG](https://github.com/DanielLetto2020/LiteEditorAI/blob/main/CHANGELOG.md).

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./liteeditor-ai_*.deb`, затем иконка **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.

> Alpha: при перезагрузке окна живые терминалы подхватывают последние 128 КБ экрана; при полном закрытии приложения сохраняются только имена вкладок. Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
