**LiteEditorAI v1.1.248** — лёгкий редактор для работы с ИИ-агентами в терминале.

Скриншот можно передать агенту одной клавишей, файлы — перетащить в терминал, следующие сообщения — поставить в очередь, а запущенный dev-сервер открывается кликом по чипу порта.

## ✨ Добавлено

- **Скриншот в агента через `Ctrl+V`.** Если в буфере обмена картинка, редактор сохраняет её в папку проекта `.lite/shots/` и вставляет путь в строку ввода — Claude Code принимает изображения по пути. Папка исключена из git, старые снимки удаляются через 14 дней. Вставка текста работает как раньше.
- **Перетаскивание файлов в терминал.** Файлы и папки из файлового менеджера или из дерева «Проект» вставляются путями (с кавычками, если в имени есть пробелы).
- **Очередь промптов.** Правый клик в терминале → «Очередь промптов…». Следующее сообщение уходит само, когда агент закончил ход и ждёт ввода; во время запроса разрешения ничего не отправляется. Число сообщений в очереди видно на вкладке.
- **Чипы открытых портов.** Когда процесс во вкладке слушает порт (например, dev-сервер), в нижней панели появляется чип `:5173` — клик открывает его в браузере. Работает на Linux.

## 🌐 Локализация

- Переводы на английский и китайский снова полные, включая окно вынесенных терминалов.

Полный список изменений — в [CHANGELOG](https://github.com/DanielLetto2020/LiteEditorAI/blob/main/CHANGELOG.md).

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./liteeditor-ai_*.deb`, затем иконка **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.

> Alpha: при перезагрузке окна живые терминалы подхватывают последние 128 КБ экрана; при полном закрытии приложения сохраняются только имена вкладок. Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
