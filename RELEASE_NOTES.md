**LiteEditorAI v1.1.97** — лёгкий редактор для работы с ИИ-агентами в терминале.

**У «Задач» появилась третья вкладка «Календарь» — дата-задачи с датами, сроками и напоминалками (лента
по срокам + вид «Месяц»), плюс встроенный MCP-сервер, чтобы агент прямо из терминала мог сам ставить и
читать напоминания.**

## ✨ Добавлено
- **Вкладка «Календарь» (дата-задачи)** рядом с «Проект»/«Общие». Отдельная сущность от обычных задач:
  главная ось — **время, а не статус**. Быстрая запись «чтобы не забыть» одной строкой + дата/время +
  напоминание. Следует за активным проектом; без открытого проекта — список «Личные».
- **Лента с группами по сроку:** Просрочено · Сегодня · Завтра · На неделе · Позже · Без даты — с цветными
  индикаторами и подписями («через 2 ч», «3 дн назад»). Быстрые чипы даты (Сегодня / Завтра / +неделя).
- **Вид «Месяц»** — календарная сетка с точками по дням, навигацией по месяцам и списком выбранного дня.
- **Нативные напоминалки:** в срок приходит системное уведомление (в момент / за 10 минут / за час /
  за день); клик открывает «Календарь». Работают, пока редактор запущен.
- **Доступ агенту из терминала (MCP).** Встроенный сервер **`lite-tasks`** даёт агенту инструменты
  создавать и читать напоминания (`add_reminder` / `list_reminders` / `complete_reminder`) — например,
  «напомни через 2 дня проверить деплой». Подключается кнопкой в scope `local` (конфиг — в пользовательский
  `~/.claude.json`, **в репозиторий проекта ничего не пишется**); рядом — «Скопировать команду» и
  «Скопировать подсказку агенту».
- **Бейдж** на кнопке «Задачи» теперь учитывает напоминания, требующие внимания (просрочено + сегодня).

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.60.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
