**LiteEditorAI v1.1.96** — лёгкий редактор для работы с ИИ-агентами в терминале.

**«Мониторинг сайтов» переосмыслен: на один URL вешается сколько угодно проверок с условиями, писать
их можно словами через агента, статусов теперь четыре по цветам, а статистику за месяц видно
графиками.**

## ✨ Добавлено
- **Модель «цель → чеки».** URL стал **целью** (интервал, заголовки, режим рендера), на которую вешается
  **сколько угодно чеков** — каждый со своим условием, состоянием и уведомлением. Один опрос грузит URL
  раз и прогоняет все его чеки. Прежние сайты автоматически становятся целью с чеком «Доступность».
- **Базовые чеки — конструктор из полей** (без ИИ): HTTP-код, **поле JSON** по пути, **текст на странице**
  (есть/нет), **число/порог**, **«изменилось»**, заголовок ответа, CSS-селектор. Кнопка «Проверить
  сейчас» прогоняет правило на живом ответе.
- **Кастомные чеки через агента** — опишите словами, что проверять, и агент прямо в диалоге напишет
  мини-парсер под этот URL (видит живой сэмпл ответа, уточняется на лету, код правится вручную).
- **Четыре статуса по цветам:** 🟢 в норме · 🟡 внимание · 🔴 тревога (с уведомлением) · 🔵 инфо.
- **Режим «Графики»** и **статистика за месяц**: аптайм %, средняя задержка, дни с тревогой, полоса
  аптайма по дням и график задержки. Плюс просмотр ответа деревом/кодом/превью и справка «?».

## 🔒 Безопасность
- TLS-сертификат проверяется **по умолчанию**; самоподписанные — только явной галочкой на цель.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.60.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
