**LiteEditorAI v1.1.121** — лёгкий редактор для работы с ИИ-агентами в терминале.

**«Удалённые хосты»: дерево файлов и полноценный редактор вместо списка и просмотра.**

Файловая часть модуля показывала один уровень каталога плоским списком, а файл открывала как
неформатированный текст — без подсветки, без номеров строк, без возможности сохранить. Работать
так с сервером было нельзя. Теперь это дерево и редактор, которые пишут прямо на хост.

## ✨ Что появилось
- **Дерево каталогов с отступами.** Подкаталоги раскрываются по клику и грузятся по мере
  надобности; любую папку можно сделать корнем дерева, кнопка «вверх» поднимает уровень.
  Значки типов файлов — те же, что в дереве вивера.
- **Права и метрики на виду.** В строке — права `rwxr-xr-x`, размер и дата. В шапке открытого
  файла — права с восьмеричным `0644`, владелец и группа, размер, дата изменения, тип узла.
  Полный набор всегда есть в подсказке строки, поэтому в узкой колонке метаданные уступают
  место имени файла, ничего не теряя.
- **Символические ссылки** помечаются и разрешаются: каталог за ссылкой раскрывается как
  каталог, битая ссылка видна сразу.
- **Редактор вместо просмотра.** Номера строк и подсветка по типу файла — PHP, Go, Rust, YAML,
  Shell и сотни других языков. Копирование выделения или всего файла одной кнопкой.
- **Сохранение прямо на хост** — `Ctrl+S` или кнопка в шапке: файл уходит на сервер по SFTP/FTP.
  Несохранённые правки не теряются молча: уход к другому файлу сначала спросит.
- **Скачивание открытого файла** через системный диалог — включая бинарные файлы и файлы
  больше порога просмотра, которые в редакторе не открываются.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.61.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
