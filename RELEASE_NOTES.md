**LiteEditorAI v1.1.189** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Разбор давних pull request'ов от [@Ainour108](https://github.com/Ainour108).** Три из них ждали ответа
с июля. Мы не стали вливать их как есть — код успел разойтись с той версией, — а разобрали каждую идею и
реализовали заново на текущей кодовой базе, с проверками и защитами. Спасибо Вам за настойчивость и за
подробные описания: часть правок оказалась ещё и точным баг-репортом на наш собственный код.

Основные изменения — в модуле **«Обработка текста»**.

## ✨ Добавлено

- **Скрепка у поля ввода в AI-чате.** Раньше документ уходил агенту всегда — просто спросить его
  («как правильно пишется?», «объясни термин») было нельзя: на любую фразу приходил переписанный текст.
  Теперь приложение документа — осознанное действие, а блок «Контекст» показывает, что именно уйдёт.
- **Режим «Агент».** Две оси вместо одной: модель × режим. **«Ассистент»** отвечает текстом, а
  **«Агент»** правит файл на диске сам — так делаются задачи, которые в один ответ не помещаются:
  пройти по всем главам, свести термины к одному виду, разнести документ по файлам.
  Режим выключен по умолчанию, работает только с сохранённым файлом, спрашивает подтверждение и честно
  говорит, под git каталог или нет — то есть будет ли чем откатить правки.
- **Кнопка «Стоп».** Запущенного агента наконец можно прервать — раньше оставалось только ждать таймаута.
- **Вкладка «Содержание»** — навигация по заголовкам документа в обоих режимах, с пропуском блоков кода.
- **Свой список агентов** — файл `~/.LiteEditorAI/tpAgents.json`: добавьте любую CLI-утилиту, переопределите
  встроенную или уберите ненужную. Редактор списка — кнопкой в панели AI.
- **Автозапуск модулей.** Галочка «Открывать при запуске редактора» на плитке модуля — нужные окна
  открываются сами.
- **Формулы из нейросетей.** Кроме `$$…$$` и `$…$` теперь понимаются `\[…\]` и `\(…\)` — ровно то, что
  выдают чат-модели. Ответ агента рендерится тем же конвейером, что и документ, а исходный вид разделителя
  сохраняется при записи файла.
- **Системное меню на macOS** — без него там не работали Cmd+C/V/X/A и Cmd+Q.

## 🐛 Исправлено

- **Инлайн-формула превращалась в мусор при сохранении.** Если блочная формула стояла внутри абзаца, она
  разрывала его, и хвост абзаца оказывался вне `<p>` — конвертер такую формулу не узнавал и записывал на
  диск текст рендера вместо `$x_i$`. Файл портился тихо, при первом же автосохранении.
- **Масштаб страницы не менял раскладку.** Он был сделан через `transform: scale()`: при увеличении низ
  документа было не доскроллить, при уменьшении оставалась пустая полоса, а в разделённом окне страница
  наезжала на панель. Теперь масштаб настоящий, запоминается между запусками и меняется с Ctrl +/−/0.
- **Отказ агента по авторизации выглядел как ответ** — да ещё и с кнопкой «Заменить», предлагавшей
  вставить «You are not logged in» прямо в документ. Теперь это понятная ошибка с командой входа,
  которую можно скопировать одним нажатием.
- **Кнопки панели форматирования сминались** в узком окне — лишние уезжают в меню «⋯».
- **Агенты не находились, если редактор запущен из меню приложений.** Графическая сессия не видит nvm и
  Homebrew, и `claude` «не найден», хотя в терминале работает. Теперь PATH берётся у логин-шелла — в фоне,
  с таймаутом, без риска подвесить запуск.

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка
  не нужна). Сборка без подписи, поэтому SmartScreen может предупредить: *Подробнее → Выполнить в любом случае*.
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому
  при **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение →
  откройте **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите
  **«Открыть всё равно»**. Кому удобнее терминал — то же одной командой:
  `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
> Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
