**LiteEditorAI v1.1.194** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Ответы агента теперь можно слушать.** Длинный ответ в терминале утомительно читать глазами —
особенно когда это разбор на два экрана. В редакторе появился модуль **«Озвучка»**: он берёт текст
из буфера обмена и читает его живым русским голосом, пока вы заняты чем-то другим.

## ✨ Добавлено

- **Модуль «Озвучка».** Открывается из меню «Модули», палитры (`Ctrl+K`) или квикбара. Скопировали
  кусок ответа — он сразу в модуле, можно поправить текст и слушать. Второй вход — пункт
  **«Озвучить»** в контекстном меню терминала: выделили вывод, нажали, окно открылось и начало читать.
- **Чтение идёт по предложениям**: пока звучит текущая фраза, синтезируется следующая, поэтому длинный
  текст начинает читаться сразу, а не после полного синтеза. Отсюда же пауза, стоп, перемотка по
  фразам, подсветка читаемой фразы и клик по фразе — «читать отсюда». Выделили кусок текста — кнопка
  становится **«Озвучить выделенное»** и прочитает только его.
- **История копирований** — 200 записей с поиском, закреплением и правкой прямо в карточке. В шапке
  три тумблера: «Перехват буфера», «Читать сразу» и «Чистить текст».
- **Чистка терминального мусора** перед чтением: рамки псевдографики, остатки ANSI, спиннеры, эмодзи,
  markdown-разметка; длинные пути схлопываются до имени файла, а блок кода пересказывается как
  «блок кода, N строк» — слушать построчный код всё равно невозможно.
- **Числа, латиница и ударения.** Числа разворачиваются словами с согласованием («1,4 мегабайта»,
  «99,5 процента», «двадцать одна тысяча»), версии читаются по частям, латиница — транслитом, частые
  термины и аббревиатуры — по буквам. `Ctrl+U` ставит ударение (`з+амок`), а пять ступеней темпа
  растягивают речь, не меняя высоту голоса.

## 🔊 Что нужно для голоса

Голос синтезирует **Silero v4_ru** в отдельном процессе Python. Движок **не входит в поставку**
(модель 39 МБ, лицензия CC BY-NC-SA), поэтому нужен интерпретатор с установленным `torch`, а модель
скачивается кнопкой прямо из настроек модуля. Пути редактор ищет сам — свой каталог, переменные
окружения, `python3` из `PATH`, интерпретаторы pyenv; годится только тот, где `torch` действительно
импортируется. Если чего-то не хватает, плашка в шапке модуля честно пишет, чего именно.

## 🐛 Исправлено

- **Чтение больше не обрывается на середине.** Фраза без единой кириллической буквы («1.1.192»,
  «build ok», «(1)») роняла движок, и вместе с ней замолкал весь текст. Теперь такая фраза либо
  становится произносимой после нормализации, либо пропускается, а чтение идёт дальше.
- **Копирование во время чтения не обрывает озвучку** — новый фрагмент просто уходит в историю.
- **История и настройки модуля сохраняются между сеансами.** Правка текста не теряется при
  переключении записи и при закрытии окна, закреплённые записи не выпадают при обрезке истории,
  а слишком длинный фрагмент обрезается не молча.
- **Модель голоса не «устанавливается» из оборванной закачки**: загрузка сверяется с размером,
  проходит редиректы и не запускается дважды. Синтезированные фразы пишутся в кэш атомарно, поэтому
  обрезанный файл из прерванной сессии не будет отдан как готовая речь.
- **Перевод интерфейса не трогает ваш текст**: раньше при английской локали совпавшие со словарём
  фразы в истории и в окне чтения подменялись переводом.

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка
  не нужна). Сборка без подписи, поэтому SmartScreen может предупредить: *Подробнее → Выполнить в любом случае*.
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому
  при **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение →
  откройте **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите
  **«Открыть всё равно»**. Кому удобнее терминал — то же одной командой:
  `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
> Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
