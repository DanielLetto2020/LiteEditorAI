**LiteEditorAI v1.1.175** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Из проекта удалён Android-пульт вместе с релеем.** Подсистема удалённого управления редактором
с планшета не оправдала себя: она требовала отдельного приложения, собственного сервера-релея и
постоянного внимания, а пользы приносила заметно меньше, чем стоила. Вместо того чтобы тащить её
дальше полумёртвым грузом, мы убрали её целиком — редактор стал проще и легче.

**Последняя версия, где пульт есть, — [v1.1.173](https://github.com/DanielLetto2020/LiteEditorAI/releases/tag/v1.1.173).**
Если он вам нужен, скачайте `.apk` оттуда: он продолжит работать со своей версией редактора.
Исходники (приложение, релей, клиент на стороне ПК) никуда не пропали — они восстанавливаются
из git по тегу `v1.1.173`.

## 🗑️ Что удалено

- **Приложение пульта** — каталог `android/` целиком и его интерфейс `renderer/mobile.js`.
- **Self-hosted релей** — папка `relay/` (сервер на Python, Caddy, compose-файл). Свой релей
  поднимать больше не нужно.
- **Клиент релея на стороне ПК** — `remote.js`, кодек цветных кадров `lib/sgrline.js`,
  сборщик ассетов `scripts/build-mobile.js`, `start-remote.sh`.
- **В интерфейсе редактора:** пункт меню «Пульт (Android)», окно аккаунта релея, значок
  подключённых пультов рядом с номером версии, список устройств с блокировкой, окно одобрения
  нового устройства и раздел «Пульт» в Настройках.
- **Внутри:** канал `remote:*`, «проекция экрана» на теневых терминалах (она работала на каждую
  открытую сессию), общая папка обмена файлами с пультом, задачи и файловый браузер пульта,
  перезапуск редактора по команде извне.

## 🔧 Что это меняет для вас

- Если вы **не пользовались пультом** — ничего, кроме того, что редактор стал легче: ушли две
  зависимости (`@xterm/headless`, `ws`) и теневой терминал-двойник на каждую сессию.
- Если **пользовались** — оставайтесь на v1.1.173 или откажитесь от пульта: обновление уберёт
  его из редактора, и приложение на планшете подключиться уже не сможет.
- **В релизах теперь 6 файлов вместо 7** — `.apk` больше не выкладывается.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
> Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
