**LiteEditorAI v1.1.101** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Новый инструмент «Склейка строк» — возвращает читаемый вид тексту, скопированному из терминала.
Плюс ревизия кода редактора и его модулей: 15 исправлений, включая два критичных — перезапуск
терминала модуля больше не трогает терминал проекта с работающим агентом, а правки в таблицах баз
данных уходят параметрами вместо склейки SQL строкой.**

## ✨ Добавлено
- **«Инструменты» → «Склейка строк».** Текст из терминала приходит порванным жёсткими переносами по
  ширине окна — инструмент собирает абзацы обратно. Снимает префиксы (`│`, `>`, `⏺`, `⎿`) и рамки
  псевдографики, чистит ANSI-коды и при этом бережёт структуру: пустая строка = граница абзаца,
  списки и заголовки остаются своими строками, таблицы и блоки кода переносятся дословно.
  Переключатели работают на лету — снимать префиксы, не склеивать после точки, схлопывать пробелы,
  беречь код, убирать лишние пустые строки, чинить перенос по дефису.

## 🐛 Исправлено
- **Терминал папки модуля жил своей жизнью.** Правый клик в терминале «Моих модулей» →
  «Очистить» / «Перезапустить» действовал на терминал **активного проекта**: перезапуск убивал
  работающего там агента. Теперь команда идёт ровно в тот терминал, по которому кликнули.
- **Правки в таблице базы данных собирались в SQL склейкой строк.** Значение с обратным слэшем
  ломало оператор в MySQL, а строковый ключ вида `0123` уходил в запрос числом — `UPDATE`/`DELETE`
  попадали не в ту строку. Значения передаются параметрами, отдельно от текста запроса.
- **«Базы данных»:** при включённом автообновлении таблицы копились обработчики мыши и копии данных
  страницы — за долгую сессию это заметно съедало память.
- **Вивер:** создание файла из дерева не спрашивало про несохранённые правки, когда открыта плашка
  «файл изменён на диске» — правки терялись молча.
- **Пользовательские модули:** ошибки загрузки/удаления не попадали в лог редактора и реестр ошибок.
- **Cron-инструмент:** невыполнимое выражение подвешивало окно почти на треть секунды на каждое
  нажатие клавиши, а значения вне диапазона молча давали «нет запусков» вместо ошибки.
- **«Обработка текста»:** «Сохранить как» для HTML-документа записывало Markdown.
- **Git:** при коммите со всеми отмеченными файлами мог незаметно уехать файл, появившийся на диске
  уже после отрисовки списка (когда агент работает параллельно).
- Копирование в буфер во всех модулях переведено на внутренний мост редактора — исчезли «ошибки
  промиса» в реестре, когда буфер отказывал из-за потерянного фокуса окна.
- Нумерация SQL-вкладок больше не перескакивает после выполнения запросов.

## 🔒 Безопасность
- **Превью HTML** в вивере открывалось в песочнице с парой флагов, которая по стандарту снимает
  изоляцию. Флаг убран — относительные пути, стили и скрипты внутри превью работают по-прежнему.
- **Markdown задач и превью** (текст приходит в том числе с пульта и от MCP-сервера) разбирается
  в инертном фрагменте и очищается **до** попадания в живой документ, а не после.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.61.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
