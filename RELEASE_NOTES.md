**LiteEditorAI v1.1.100** — лёгкий редактор для работы с ИИ-агентами в терминале.

**«Внешние хранилища» доведены до зрелого состояния: 24 исправления по итогам двойного код-ревью
плюс большая порция функционала — сортировка и фильтр, мультивыбор, скачивание папок, пресеты
11 провайдеров и связка с «Контейнерами» (MinIO подключается одним кликом).**

## ✨ Добавлено
- **Сортировка** объектов по имени/размеру/дате, **фильтр** по текущей папке и **мультивыбор**
  с пакетными «Скачать» / «Удалить».
- **«Скачать папку…»** — рекурсивное скачивание всего префикса с общим прогрессом;
  **«Копировать в…» / «Переместить в…»** для объектов.
- **Пресеты провайдеров**: Amazon S3, MinIO, Yandex Object Storage, Backblaze B2, DigitalOcean
  Spaces, Wasabi, GCS (interop), Cloudflare R2, Selectel, VK Cloud, Timeweb — endpoint, регион
  и path-style подставляются сами.
- **«Контейнеры» → «Внешние хранилища»:** у MinIO-контейнера — кнопка-облако, подключение
  создаётся с готовым endpoint и ключами из окружения контейнера.
- **«Открыть в вивере редактора»** и **«Путь в терминал»** (`s3://…`) в меню объекта;
  восстановление открытых вкладок после перезапуска.
- Вкладка FTP убрана из полосы адаптеров: FTP/SFTP полностью закрывает модуль «Удалённые хосты».

## 🐛 Исправлено
- Перетаскивание файла на подключение «только чтение» уничтожало окно модуля (уводило его на
  локальный файл) — защита теперь во всех окнах-модулях.
- Защитный лимит удаления папки срабатывал **после** удаления — теперь объекты считаются заранее,
  при превышении не удаляется ничего.
- Гонки при быстрых переключениях подключений/папок: чужие бакеты, чужие страницы пагинации и
  чужой статус публичности больше не подмешиваются.
- Форма теряла данные: «анонимно» стирал ключи; Session Token нельзя было увидеть и очистить.
- «Показать ещё» сбрасывал прокрутку; завершение фоновой загрузки выбивало из просмотра файла.
- Дерево не видело созданные/удалённые папки; ошибка узла кэшировалась навечно; не работала
  подсветка активного узла.
- Утечки памяти и слушателей, обрыв живой передачи при пересохранении подключения, молча
  докачивавшееся «отменённое» скачивание.
- Понятные ошибки: истёкший STS-токен, Glacier, таймауты, «объект больше 5 ГБ», различение
  «неверный регион» / «битые ключи».

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.61.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
> Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
