**LiteEditorAI v1.1.206** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Окно «Проект» переработано: код и Git в раскладке, которая читается с первого взгляда, как в PhpStorm,
но по-своему.** Плюс встроенные шрифты — русский интерфейс больше не набирается запасным системным шрифтом.

![Окно «Проект»](https://raw.githubusercontent.com/DanielLetto2020/LiteEditorAI/main/assets/screenshots/workspace.png)

## 🔄 Изменено

- **Раскладка окна «Проект»**: сверху панель инструментов — ветка, Pull и Push со счётчиками коммитов, «Найти
  файл» (`Ctrl+P`); слева полоса инструментов — Проект, Коммит со счётчиком изменений, Git, поиск, структура,
  TODO, закладки; дальше дерево, вертикальная колонка открытых файлов и редактор.
- **Шапка редактора**: путь файла «хлебными крошками», «Код · Рядом · Превью» прямо у файла, подписанные
  «Изменения», «Авторы», «История», всё редкое — в меню «⋯».
- **Git**: история — одна строка на коммит, втрое больше истории на экране; раздел «Коммит» с общим флажком и
  сообщением внизу.
- **Шрифты**: встроены кириллица Inter и JetBrains Mono для кода.

## ✨ Добавлено

- Строка состояния: ветка, изменения, позиция, отступы, кодировка, концы строк, язык.
- Пустой редактор подсказывает, как найти файл, и показывает недавние.
- «Свернуть всё» и «показать открытый файл» в дереве; коммит по `Ctrl+Enter`.

## 🐛 Исправлено

- После коммита, отката, stash или pull файлы больше не остаются «изменёнными» в дереве и вкладках.
- Папка с изменёнными файлами снова подсвечивается.
- Полный список — в [CHANGELOG](https://github.com/DanielLetto2020/LiteEditorAI/blob/main/CHANGELOG.md).

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка
  не нужна). Сборка без подписи, поэтому SmartScreen может предупредить: *Подробнее → Выполнить в любом случае*.
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому
  при **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение →
  откройте **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите
  **«Открыть всё равно»**. Кому удобнее терминал — то же одной командой:
  `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: терминалы переживают перезагрузку окна, но не перезапуск редактора (сохраняются только
> имена вкладок). Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
