**LiteEditorAI v1.1.93** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Вкладка-терминал теперь называется так, как её называет агент. Claude Code (как и любой шелл)
пишет в заголовок окна текущую задачу или статус — редактор подхватывает этот заголовок в имя
вкладки вместо безликого «Терминал N». Ручное имя (двойной клик по вкладке) по-прежнему главнее и
переживает перезапуск.**

## ✨ Добавлено
- **Имя вкладки из заголовка терминала**: агент/шелл пишет в заголовок окна текущую задачу — и
  вкладка называется так же, а не «Терминал 1/2/3». Длинный заголовок аккуратно обрезается по
  ширине вкладки. Один и тот же заголовок не дёргает панель вкладок.
- **Ручное имя главнее**: если вы переименовали вкладку двойным кликом, заголовок терминала её
  больше не перебивает; этот выбор сохраняется между перезапусками редактора.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.60.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
