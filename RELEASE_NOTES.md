**LiteEditorAI v1.1.128** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Задачи Jira из нескольких аккаунтов прямо в редакторе, синхронизация рабочих копий между машинами
и закрытые предупреждения безопасности во всех зависимостях.**

Большой накопительный релиз: новый модуль задач, работа с двумя машинами без ручного копирования
файлов и полный проход по зависимостям — с шести предупреждений до нуля.

## ✨ Что появилось

### 🧩 Модуль «Jira»
- **Несколько аккаунтов сразу**, Cloud и Server/DC — одним кодом. Список задач агрегируется по всем
  подключениям: пресеты JQL и свой JQL, аккордеон по статусам, избранное с перетаскиванием.
- **Автообновление** от 1 до 60 минут с подсветкой непрочитанных и счётчиком задач, появившихся
  за последние 8 часов. Фильтры по доскам, спринтам, статусам и типам задач.
- **Карточка задачи** — переходы статуса и учёт времени над тремя вкладками: «Описание»,
  «Связи и обсуждение», «Люди и поля задачи». Описание и комментарии очищаются от wiki-разметки,
  блоки кода сохраняются; описание и задача копируются целиком.
- **Схема чужой Jira обнаруживается, а не хардкодится**: статусы — через `statusCategory` и `/status`,
  переходы — из ответа сервера, кастомные поля (спринт, тип задачи) — через `/field`, пагинация —
  курсором или `startAt` по факту. Токен хранится зашифрованным через `safeStorage` и в интерфейс
  не отдаётся — наружу уходит только признак «токен есть».

### 🔄 Синхронизация рабочих копий между машинами
- В карточке проекта появилась метка **`sync`**: зелёная — проект синхронизируется, серая — ещё нет.
- **Клик по серой открывает подключение** с видимым чеклистом: связь со второй стороной → проект
  на той стороне (нет — создаётся) → первая передача файлов → запись в настройки. Каждый шаг
  отчитывается по ходу; сбой останавливает процедуру и называет причину человеческим текстом.
- **Расхождения не решаются молча.** Если файлы есть с обеих сторон и различаются, редактор
  спрашивает, чью версию считать верной; заменённое уходит в корзину, как при обычной сверке.
- Метка появляется только там, где синхронизация настроена.

## 🔒 Безопасность
- **Все предупреждения зависимостей закрыты — 6 → 0.** `electron` 42.4.0 → 42.10.1, `undici`
  6.27.0 → 6.28.0 и 7.28.0 → 7.29.0, `dompurify` 3.4.12 → 3.4.14, `js-yaml` 4.3.0 → 4.3.1,
  `fast-uri` 3.1.4 → 3.1.6, `brace-expansion` → 5.0.9. Закрыты: раскрытие данных между
  пользователями и падение при разборе директив кеша, рассинхронизация ответов в перехватчике
  повторов, CRLF-инъекция через тип тела запроса; подмена узла через обратный слэш; квадратичный
  расход процессора при разборе `!!omap`; XSS через отсоединённое поддерево после снятия хука;
  отказ в обслуживании на несвязанных промежуточных массивах.
- **Путь проекта больше не может стать командой.** В служебных вызовах оболочки путь подставлялся
  в двойных кавычках — а внутри них оболочка разворачивает подстановку команд. Где оболочка не
  нужна, она убрана; где нужна, путь экранируется одинарными кавычками.

## 🛠 Под капотом
`node-pty` пересобран под новый Electron. Английский и китайский словари снова на 100 %. Гейты
стиля, типов, тестов и мутационного тестирования (80,2 % при пороге 79) зелёные.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.61.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
