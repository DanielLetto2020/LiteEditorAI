**LiteEditorAI v1.1.104** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Релей: секрет администратора больше не передаётся в строке запроса.**

## 🔒 Безопасность
- **`GET /reports`** (просмотр присланных отчётов) требовал секрет параметром URL — `/reports?key=…`.
  Строка запроса попадает в логи веб-сервера и обратного прокси, в историю браузера и в заголовок
  `Referer`, то есть секрет релея разъезжался по местам, где его быть не должно. Теперь эндпоинт
  принимает его заголовком `Authorization: Bearer <RELAY_SECRET>` — так же, как остальные защищённые
  ручки релея (`/sessions`, `/logout`, `/password`, `/devices/revoke_all`). Сравнение по-прежнему
  через `hmac.compare_digest`.

Идея и патч — [@anupamme](https://github.com/anupamme), спасибо ([#9](https://github.com/DanielLetto2020/LiteEditorAI/pull/9)).

⚠️ **Для тех, кто держит свой релей:** после обновления вызовы `/reports?key=…` начнут отвечать `403`.
Замените на заголовок:
```bash
curl -H "Authorization: Bearer $RELAY_SECRET" https://<ваш-хост>/reports
```
Редактора и Android-пульта изменение не касается — этот эндпоинт они не используют, обновлять
приложение из-за него не нужно.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.61.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
