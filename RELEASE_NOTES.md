**LiteEditorAI v1.1.173** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Релиз целиком про надёжность: двадцать четыре круга сквозного аудита, 36 находок, каждая
проверена запуском. Больше всего досталось сохранению — нашлись пути, на которых работа
пропадала молча. Из нового: автоввод команды в свежем терминале и переделанная канва
`CLAUDE.md`.**

## 🐛 Потеря и порча данных — закрыто

- **«Обработка текста» уничтожала markdown при сохранении.** Конвертер покрывал только то, что
  рисует свой тулбар, но через него идёт сохранение **любого** `.md` из дерева проекта — в том
  числе автосейвом через 1.5 с после первой правки. На README проекта это означало: из 41 ссылки
  оставалось 0, из 4 блоков кода 0, из 52 строк таблиц 0, из 10 картинок 0. Теперь на месте
  ссылки, картинки, блоки кода с языком, таблицы, заголовки H4–H6, вложенные списки.
- **YAML front matter (`---` в начале файла) переписывался в заголовок** — под удар попадали
  правила проекта, роли агентов в `.claude/agents/*.md` и заметки Obsidian.
- **Правки, набранные во время записи, помечались сохранёнными и терялись** — и в вивере, и в
  «Обработке текста». Уход на другую вкладку во время записи снимал флаг «не сохранено»
  с **чужой** вкладки, и она закрывалась без вопроса.
- **Уход в «Превью» или «Дифф» оставлял правку висеть в памяти:** автосейв в этих режимах молчит,
  а выход из редактора закрывает окна модулей без вопроса. Теперь файл пишется при входе в режим.
- **Двойной клик по файлу в дереве открывал две вкладки одного файла** — правки в одной затирались
  сохранением другой.
- **Файлы писались неатомарно.** Обычная запись сперва обнуляет файл, а вивер делает это каждые
  400 мс: краш, нехватка места или выключение оставляли обрезанный файл. Теперь на диске либо
  старая версия целиком, либо новая — с сохранением прав. То же для массовой замены по проекту,
  базы SQLite и базы паролей KeePass.
- **Неудачная запись базы SQLite выдавалась за успех** — «Применено», хотя на диске ничего нет.
- **Откат правок в git не снимал копию в локальную историю** — работа исчезала безвозвратно.
- **Два запущенных редактора портили общий файл настроек** — для `projects.json` это потеря всего
  списка проектов.

## 🔒 Безопасность

- **Запрет «только чтение» для баз обходился дефисом внутри строки:** `SELECT 'a--'; DROP TABLE t;`
  проходил фильтр. Разбор SQL переписан одним проходом.
- **Скачивание папки из S3 могло записать файлы выше выбранного каталога** — ключ объекта из чужого
  бакета уводил запись наружу и затирал файлы на диске.

## 🐛 Зависания и утечки

- **Вечный цикл записи в лог и на диск:** одна неудачная отправка в окно порождала ошибку, ошибка
  возвращалась в реестр, реестр будил подписчика — и так каждые 0,7 с до конца работы редактора.
- **Закрытие окна модуля не обрывало его запросы к агенту** — `claude -p` доживал до таймаута,
  тратя минуты и токены впустую.
- **Закрытие «Контейнеров» не гасило `logs -f` и `exec -it`**, «Удалённых хостов» — SSH-сессии.
- **Параллельные запросы открывали лишние соединения и SSH-туннели**; двойной клик по порту
  контейнера поднимал два туннеля вместо одного.
- **Проверка видеокарты отъедала графические контексты у самих терминалов.**

## ✨ Что появилось

- **Автоввод в новом терминале.** Настройка (по умолчанию `claude`) сама пишет слово в каждый новый
  терминал проекта — без Enter, остаётся подтвердить или дописать. Пустое поле — как раньше.
- **Канва «Контекста» — это и есть ваш `CLAUDE.md`:** широкие карточки, раскладка в порядке разделов
  файла и «Спросить агента» прямо из модалки раздела.
- **Падения внутри окон модулей теперь попадают в лог и реестр ошибок** — раньше пропадали молча.

## 🧪 Тесты

Три новых набора в `npm test`: фильтр «только чтение» для SQL (35 проверок), защита путей при
скачивании из хранилища (21) и реестр ошибок (7). Набор по-прежнему запускается на чистом node,
без установленных зависимостей.

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.62.0-debug.apk`** — пульт для Android.

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
