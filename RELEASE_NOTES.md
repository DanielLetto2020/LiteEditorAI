**LiteEditorAI v1.1.136** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Модуль «Контекст» переделан: канва — это и есть ваш `CLAUDE.md`, а рядом появились память
агента, файлы `.claude` и разбор истории диалогов. Плюс закрыта дыра, из-за которой окно
редактора могло уйти на внешний сайт вместе с доступом к файлам.**

## 🔒 Безопасность

- **Окно с мостом больше не уходит на внешние адреса.** Служебный мост подключается к каждому
  документу окна, поэтому окно, ушедшее по обычной ссылке из превью markdown, отдавало странице
  доступ к файлам, хранилищу и буферу обмена — а тексты в превью приходят из чужих репозиториев
  и от агента. Теперь окну разрешены только его собственные страницы, любой другой адрес
  открывается в системном браузере.
- **Атомарная запись не затирает символическую ссылку.** Если `CLAUDE.md` или конфиг положены
  ссылкой на общий шаблон, правка больше не превращает ссылку в копию, оставляя общий файл
  без изменений.

## ✨ Что появилось

### 🧠 Модуль «Контекст» — канва как сам файл

`CLAUDE.md` показывается разделами: виден вес каждого куска в токенах и файла целиком. Правка
раздела сразу уходит в файл, а прежняя версия — в историю: **50 копий**, замок от ротации,
комментарий к версии и дифф с текущим файлом блоками. Правку, сделанную самим агентом, модуль
замечает и тоже сохраняет — откатить её можно так же, как свою. Профили и тумблеры блоков убраны:
канва больше не может разойтись с файлом.

### 📓 Вкладка «Память»

Что Claude Code запомнил по проекту: факты с описанием и типом, вес индекса и тел отдельно, связи
между фактами в обе стороны, расхождения индекса с файлами. Избранное, сортировки, поиск, правка
файла целиком и удаление в корзину — с восстановлением и файла, и его строки в индексе на прежнее
место.

### 📁 Вкладка «Файлы»

Дерево того, чем настраивают агента: `.claude` проекта и `~/.claude`. У папок видно число вложенных
объектов и вес, у файлов — размер и дату. Редактор с историей копий, превью markdown, сворачивание
JSON, разбор JSONL по записям, проверка синтаксиса shell. Большие файлы открываются частями: в
памяти всегда около 384 КБ, сколько бы мегабайт ни было в файле.

### 💬 Вкладка «Анализ диалогов»

Извлечение долгоиграющих правил из истории разговоров с агентом: по длинной сессии едет плавающее
окно, можно выбрать конкретные разговоры списком с поиском и группировкой по дням. Реестр копится
между перезапусками; выбранные правила дописываются в `CLAUDE.md`, а для скиллов и команд создаются
заготовки файлов.

## 🐛 Исправлено

- Правка `CLAUDE.md` вне модуля не попадала в историю — откатить агента было нечем.
- Канва залипала на прежнем проекте при переключении на другой вкладке и могла записать чужой текст.
- Окно продолжало показывать данные закрытого проекта, а правка ушла бы в его файл.
- Закрытие окна съедало несохранённый текст в редакторе раздела, памяти или файла `.claude`.
- Отступный блок кода в начале раздела терял отступ при сохранении.
- Живые связи памяти помечались битыми: ссылка указывает на слаг из фронтматтера, а сверялась
  только с именем файла.
- Кнопка «Проверить синтаксис» падала ровно тогда, когда находила ошибку.
- Большие файлы теряли по строке на стыке подгружаемых окон.
- Гонки при загрузке памяти и дерева файлов, потеря фокуса в поиске, дубли диффов при быстрых
  кликах по версиям.
- Убран мёртвый код, оставшийся от переделки канвы (на нём падала проверка стиля).

### ⬇️ Что скачать
- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка **LiteEditorAI** в меню.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка не нужна).
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому при
  **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение → откройте
  **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите **«Открыть всё
  равно»**. Кому удобнее терминал — то же одной командой: `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.
- 🤖 **`liteeditor-pult-0.61.0-debug.apk`** — пульт для Android (без изменений в этом релизе).

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
