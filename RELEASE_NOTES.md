**LiteEditorAI v1.1.203** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Индикатор Claude Code больше не мигает и показывает три честных состояния, окна модулей следуют вашему
оформлению, а «Базы данных», «Контейнеры» и «Удалённые хосты» прошли аудит.**

![LiteEditorAI](https://raw.githubusercontent.com/DanielLetto2020/LiteEditorAI/main/assets/screenshots/hero.png)

## ✨ Новое

- **Индикатор Claude Code по его собственному отчёту**: спиннер — Claude работает (даже пока команда
  идёт молча), янтарный — ждёт вашего решения (разрешение, вопрос, диалог), зелёный — ход окончен.
  Строка статуса и набор текста больше не включают спиннер.
- **Уведомление называет причину** — «Claude просит разрешения», «Claude задал вопрос» — и открывает
  нужную вкладку. Уведомления теперь на языке интерфейса.
- **Окна встроенных модулей следуют оформлению главного окна**: вся палитра и прозрачность фона.

## 🐛 Исправлено

- Индикатор у простаивающего Claude мигал то спиннером, то янтарным.
- **Базы данных**: операции одного подключения идут по очереди; большие числа, даты, JSON и двоичные
  поля Postgres/MySQL не искажаются; составные внешние ключи и DDL Postgres читаются верно; «запрос под
  курсором» и `:параметры` понимают строки, комментарии и `$$`-тела; экспорт не теряет кавычки и
  предупреждает об усечении; переписка AI-DB сохраняется при закрытии окна.
- **Контейнеры**: образ с несколькими тегами удаляется по имени и тегу, ссылки на каталоги открываются.
- **Удалённые хосты и SSH-туннель БД**: зашифрованные ключи по умолчанию больше не ломают подключение.
- Полный список — в [CHANGELOG](https://github.com/DanielLetto2020/LiteEditorAI/blob/main/CHANGELOG.md).

## 🔒 Безопасность

- Имена контейнеров, образов и томов проверяются, прежде чем попасть в команду docker/podman.
- В ответах AI-DB разрешены только встроенные картинки.

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка
  не нужна). Сборка без подписи, поэтому SmartScreen может предупредить: *Подробнее → Выполнить в любом случае*.
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому
  при **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение →
  откройте **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите
  **«Открыть всё равно»**. Кому удобнее терминал — то же одной командой:
  `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: терминалы переживают перезагрузку окна, но не перезапуск редактора (сохраняются только
> имена вкладок). Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
