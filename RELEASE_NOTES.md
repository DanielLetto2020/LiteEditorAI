**LiteEditorAI v1.1.198** — лёгкий редактор для работы с ИИ-агентами в терминале.

**Окна модулей открываются в 2–3 раза быстрее, редактор быстрее стартует, а несколько тихих сбоев больше не случаются.**

## 🐛 Исправлено

- **Настройки, изменённые в одном окне, могли пропасть после перезапуска.** Окна записывали настройки
  целиком из своей копии, и последняя запись затирала чужие изменения: язык интерфейса откатывался
  на русский, если после его смены поменять тему, а вид «Задач» сбрасывался от `Ctrl+=` в редакторе.
  Теперь каждое окно записывает только то, что изменило само.
- **При заполненном диске журнал ошибок мог зациклиться** и нагружать процессор до перезапуска
  редактора. Теперь сбойный канал журнала отключается на минуту.
- **Упавшее окно редактора оставалось белым.** Теперь оно перезагружается само (терминалы этого окна
  при этом закрываются), а если падает снова и снова — редактор спрашивает, что делать.
- **Повторный клик по ярлыку открывал второй экземпляр редактора**, и оба перезаписывали список
  проектов и настройки. Теперь второй запуск показывает уже открытое окно.
- **При множестве открытых вкладок терминалы теряли аппаратную отрисовку.** Теперь WebGL держат
  четыре последних показанных терминала, остальные получают его при переключении.
- **Локальная история файлов росла без ограничений** — в неё попадали логи и сборочные файлы.
  Теперь она хранится 30 дней и занимает не больше 300 МБ, история удалённого файла держится ещё
  неделю. Первая чистка проходит через минуту после запуска.
- **Проект больше 10 000 папок** больше не обходится заново при каждом переключении на него.

## ⚡ Быстрее

- **Окна модулей открываются в 2–3 раза быстрее и занимают меньше памяти**: окно загружает только
  свой модуль, подсветка редких языков подгружается при первом открытии такого файла.
- **Старт примерно на четверть быстрее**: драйверы баз данных, SSH, Kafka и S3 загружаются, только
  когда вы открываете соответствующий модуль.
- **Вывод терминала передаётся в окно пачками** — сообщений между процессами примерно в 140 раз меньше.
- При перетаскивании разделителя Claude Code и другие программы в терминале перерисовывают экран один
  раз по окончании, а не десятки раз в секунду.
- Индикатор «работает / ждёт ответа», панель вкладок, список проектов и меню в трее больше не делают
  лишней работы.

## ⬇️ Что скачать

- 🐧 **`.deb`** — Ubuntu / Debian (x64): `sudo apt install ./LiteEditorAI_*.deb`, затем иконка
  **LiteEditorAI** в меню. Обновления попросят пароль администратора.
- 🐧 **`.tar.gz`** — Linux (x64), портативная сборка: распакуйте в любую папку внутри домашнего
  каталога и запустите `liteeditor-ai`. Установка не нужна, права root не нужны, **обновления
  ставятся без пароля** — рекомендуем этот вариант, если вы не привязаны к системному пакету.
- 🪟 **`.zip`** (win) — Windows (x64), portable: распакуйте и запустите `LiteEditorAI.exe` (установка
  не нужна). Сборка без подписи, поэтому SmartScreen может предупредить: *Подробнее → Выполнить в любом случае*.
- 🍎 **`.dmg`** — macOS: `-arm64` для Apple Silicon, `-x64` для Intel. Сборка без подписи Apple, поэтому
  при **первом** запуске разрешите её **без терминала**: запустите приложение → закройте предупреждение →
  откройте **Системные настройки → Конфиденциальность и безопасность** → пролистайте вниз и нажмите
  **«Открыть всё равно»**. Кому удобнее терминал — то же одной командой:
  `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`.

> Alpha: живой процесс терминала не переживает перезапуск редактора (сохраняются только имена вкладок).
> Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).
