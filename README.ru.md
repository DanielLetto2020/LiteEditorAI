### Код пишет агент. Здесь вы за ним следите.

(Claude Code, Codex, Gemini CLI, Qwen…), а не набирает каждую строку сам.

*Три агента в трёх проектах. Вкладка сама назвалась задачей, над которой работает агент; янтарные точки —
два агента, ждущие ответа, а бейдж в шапке их считает.*

## Зачем

Привычный редактор спроектирован под человека, который набирает код. Сегодня этот человек
большую часть дня **читает, направляет и проверяет агента**. Форма перестала подходить:

- В центре работы уже не файл, а **разговор с агентом в терминале**.
- Тяжёлый IDE под это избыточен, а голый терминал слеп: какой агент закончил? какой ждёт вашего
  ответа? что он только что наменял в файлах?
- Запустите агентов в трёх проектах сразу — и к обеду потеряете нить.

LiteEditorAI ставит терминал в центр, а всё остальное — ровно на одну кнопку в стороне.
Открыли папку и работаете: ни мастера проекта, ни языковых серверов настраивать не нужно.

## Чем отличается

### 1. Все агенты — одним взглядом

![Переключение проектов с живыми агентами](assets/screenshots/demo.gif)

У каждого проекта свои **живые shell-вкладки**: агент в одной, dev-сервер в другой, разовая команда
в третьей. Вкладка **сама называется по заголовку терминала** — для агента это значит «задача, над
которой он прямо сейчас работает».

Светофор показывает состояние, не переключаясь никуда: **работает** (спиннер) · **ждёт вашего ответа**
(янтарный) · **готов** (зелёный). Индикатор на карточке — агрегат по всем вкладкам проекта, а в шапке
живёт счётчик: **сколько агентов ждут именно вас**. Плюс уведомления.

На ролике выше — ещё палитра команд (`Ctrl+K`) и каталог модулей.
[Видео в полном размере](assets/screenshots/demo.mp4).

### 2. Видеть, что агент наменял

![Код и git одним окном](assets/screenshots/workspace.png)

Окно **«Проект»** держит вивер кода и git рядом, в духе PhpStorm: дерево файлов **само обновляется**, пока
агент правит, подсветка всех языков, миникарта, автодополнение, **blame**-аннотации, **дифф vs HEAD в две
колонки**, замена по проекту, **режим агента** (слой авторства правок поверх кода, «спросить агента» из
контекстного меню) и — страховка — **локальная история файлов с откатом** для всего, что агент изменил до
вашего коммита.

Git в том же окне: выборочный коммит чекбоксами, amend, commit / push / pull / fetch, stash, история файла,
cherry-pick / revert, разрешение конфликтов на три панели, ветки.

### 3. Держать контекст агента в порядке

Модуль **«Контекст»** показывает `CLAUDE.md` проекта разделами на канве: видно вес каждого куска
в токенах и файла целиком. Правка раздела сразу уходит в файл, а прежняя версия — в историю:
50 копий, замок от ротации, комментарий к версии и дифф с текущим файлом. Правку, сделанную самим
агентом, модуль замечает и тоже сохраняет — откатить её можно так же, как свою.

Рядом три вкладки: **«Память»** — что Claude Code запомнил по проекту (факты, связи между ними,
расхождения с индексом, корзина с восстановлением); **«Файлы»** — дерево `.claude` проекта и
`~/.claude` с редактором, историей копий и просмотром больших файлов частями; **«Анализ диалогов»** —
извлечение долгоиграющих правил из вашей истории разговоров с агентом, с записью их в `CLAUDE.md`
или созданием заготовок скиллов и команд.

## Установка

Готовые сборки — на странице [**Releases**](https://github.com/DanielLetto2020/LiteEditorAI/releases).

| ОС | Как |
|---|---|
| **Ubuntu / Debian** (x64) | `sudo apt install ./LiteEditorAI_*.deb` — поставит приложение и подтянет зависимости. Обновления попросят пароль администратора (пакет лежит в системном каталоге). |
| **Linux portable** (x64) | Скачайте `LiteEditorAI-*-linux-x64.tar.gz`, распакуйте в домашний каталог, запустите `liteeditor-ai`. Без root, и **обновления ставятся в один клик**. |
| **Windows** (x64) | Скачайте `LiteEditorAI_*-win.zip`, распакуйте в любую папку, запустите `LiteEditorAI.exe`. Установка не нужна. Без подписи — SmartScreen: «Подробнее» → «Выполнить в любом случае». |
| **macOS** (arm64 / x64) | Скачайте `.dmg` под свой процессор (`-arm64` для M1–M4, `-x64` для Intel), перетащите в «Программы». Сборка без подписи Apple, поэтому при первом запуске: «Системные настройки → Конфиденциальность и безопасность» → «Открыть всё равно» (или `xattr -dr com.apple.quarantine /Applications/LiteEditorAI.app`). |
| **Из исходников** | `npm install && npm start` (нужен Node.js 22+) |

**Обновление — в один клик.** Редактор сам проверяет релизы на GitHub, качает новую версию в фоне и
зажигает в шапке плашку **«Перезапустить»**: нажали — редактор закрылся и открылся уже обновлённым,
без похода на страницу загрузки. Портативные сборки (Linux `tar.gz`, Windows `zip`, macOS `.app`)
обновляются без пароля; установка из `.deb` один раз спросит пароль администратора. Режим обновления —
в **Настройках → Обновления**.

открытых окон восстанавливается при следующем запуске. Окна, привязанные к проекту, следуют за активным
проектом редактора.

**🧩 Свои модули (плагины).** «Модули → Создать модуль…» открывает менеджер: вы задаёте имя — редактор
создаёт заготовку и **открывает терминал прямо в её папке**, где код модуля пишет **любой ваш ИИ-агент**
по встроенной спецификации (`GUIDE.md` и подсказки кладутся рядом). Готовый модуль появляется на панели
«Мои модули» — его можно перезагрузить на лету, открыть папку или удалить. Простой пример (калькулятор)
уже в комплекте, спецификация для авторов — в каталоге [`module-kit/`](module-kit/).

| ⚡ **Квикбар** | Полоса кнопок-иконок под терминалом: вынесите нужные модули в один клик, ставьте разделители, настраивайте состав и порядок — всё сохраняется. |
| 🗂 **Порядок в проектах** | Категории (создать / переименовать / свернуть, плюс «Архив»), избранное с ручным порядком карточек (перетаскивание), акцент-цвета, авто-скан папки с проектами. |
| 🎨 **6 тем оформления** | Неоморфизм (по умолчанию), Стекло, Material, Catppuccin, Gruvbox, Aurora. Терминал перекрашивается под тему. |
| 🖼 **Рамка окна** | Тонкая настраиваемая обводка по периметру редактора и каждого окна модуля — чтобы тёмные окна не сливались с тёмным фоном. Палитра из 8 оттенков, необязательная плавная пульсация. |
| 🟩 **Заставка-«матрица»** | Спокойный полноэкранный «дождь» символов: кнопка ✨ в шапке или автозапуск после простоя. Агенты продолжают работать; выход — клик, Esc или любая активность. |
| 🔔 **Уведомление об обновлениях** | Редактор сам сверяется с последним релизом и подсвечивает плашку у номера версии (само ничего не ставит). |
| 🪶 **Без перегруза** | Ничего не настраивать на старте, маленькая панель настроек; `Ctrl+C` / `Ctrl+V` в терминале работают в любой раскладке на Linux и Windows. |

## Языки

Интерфейс есть на **русском, английском и китайском** — язык выбирается в «Настройки → Язык интерфейса»
и применяется сразу, без перезапуска и без переоткрытия окон модулей.

Каждый язык — обычный JSON, где ключ — исходная строка:

```
locales/ru.json              # поставляется с приложением
~/.LiteEditorAI/locales/     # ваши файлы; перекрывают встроенные
```

Чтобы добавить язык, скопируйте `locales/ru.json`, переведите значения, положите файл как `<код>.json`
и выберите его в настройках — пересобирать ничего не нужно. Через ту же папку можно поправить одну
неудачную формулировку в готовом языке: положите в свой файл только этот ключ. Команда
`node scripts/i18n-extract.js` обновляет словарь-источник и показывает, насколько полна каждая локаль;
непереведённые строки показываются по-английски, а не по-русски.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+T` / `Ctrl+Shift+W` | новая / закрыть вкладку терминала |
| `Ctrl+PageUp` / `Ctrl+PageDown` | переключение вкладок терминала |
| `Ctrl+Enter` | перенос строки в терминале (продолжить ввод, не выполнять) |
| `Ctrl+C` / `Ctrl+V` | копировать выделение / вставить (в любой раскладке) |
| `Ctrl+\` | режим «один терминал» |
| `Ctrl+K` | палитра команд |
| `Ctrl+F` / `Ctrl+Shift+F` | поиск в терминале или файле / по выводу всех открытых терминалов |
| `Ctrl+S` | сохранить файл |
| `Ctrl+Shift+R` | замена по проекту (в окне «Проект») |
| `Ctrl+1..9` / `Ctrl+Tab` | переключение проектов |
| `Ctrl + +/−` · `F11` | размер шрифта · полный экран |

## Статус

**Alpha** — активно дорабатывается. Вкладок-терминалов у проекта сколько нужно, и их **имена** переживают
перезапуск (сами процессы — нет). Вивер открывает один файл за раз и не берёт файлы больше 2 МБ. Это
вивер с правкой, а не замена движку рефакторинга из вашего IDE — так задумано.

и self-hosted релей в папке `relay/`. Последний релиз, где они были, —

или восстановить исходники по тегу.

Баги и идеи — в [Issues](https://github.com/DanielLetto2020/LiteEditorAI/issues).

## Сборка из исходников

```bash
npm install        # зависимости + сборка node-pty под Electron
npm start          # сборка фронта + запуск
```

Требуется Node.js 22+ (Linux / Windows x64; сборки macOS делаются только на macOS).
Для разработчиков — [CONTRIBUTING.md](CONTRIBUTING.md).

### Pull request'ы

Прямой доступ к репозиторию не нужен — участие идёт через форк. Сделайте форк, ответвитесь от ветки
**`contrib`** и откройте PR **в `contrib`** (не в `main`). Принятые правки мейнтейнер переносит в разработку
и выпускает в одном из ближайших релизов; ревью — вручную, по усмотрению мейнтейнера. Подробнее —
в [CONTRIBUTING.md](CONTRIBUTING.md).
